# Oh-My-System

여러 프로젝트에서 반복해서 사용할 개발 원칙과 도구 선택 기준을 정리한다. 실제 기능 명세와 실행 방법은 각 프로젝트에서 관리한다.


## 문서

| 문서 | 내용 |
| --- | --- |
| [DEVELOPMENT_PRINCIPLES](DEVELOPMENT_PRINCIPLES) | 구현, 검증, 기록에 관한 공통 원칙 |
| [DESIGN_PRINCIPLES.md](DESIGN_PRINCIPLES.md) | 화면 구성과 디자인 시스템 문서화에 관한 원칙 |

API 설계 원칙과 도구 목록은 실제 사례를 정리하면서 하나씩 추가한다. 새 문서를 만들면 이 표에 연결한다.
