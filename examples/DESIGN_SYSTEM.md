# 디자인 시스템 작성 예시

프로젝트의 `DESIGN_SYSTEM.md`에 실제로 사용하는 값을 기록한다. 아래 값은 작성 형식을 보여주는 예시이며, 프로젝트에 맞게 정한다.

## 색상

| 이름 | 값 | 사용처 |
| --- | --- | --- |
| `color-primary` | `#2457D6` | 주요 버튼, 강조 |
| `color-text` | `#1F2937` | 본문 |
| `color-error` | `#B42318` | 오류 안내 |

## 글꼴

| 이름 | 값 | 사용처 |
| --- | --- | --- |
| `font-body` | `16px / 1.5` | 본문 글자 크기 / 줄 높이 |
| `font-heading` | `24px / 1.3` | 페이지 제목 |

## 간격과 형태

| 이름 | 값 | 사용처 |
| --- | --- | --- |
| `space-small` | `8px` | 요소 사이의 작은 간격 |
| `space-medium` | `16px` | 섹션 내부 간격 |
| `radius-button` | `8px` | 버튼 모서리 |

## 컴포넌트

### 주요 버튼

- 높이: `40px`
- 배경색: `color-primary`
- 상태: 기본 / 마우스 오버 / 키보드 포커스 / 비활성 / 진행 중
- 진행 중에는 작업 상태를 표시하고 중복 실행을 방지한다.

코드에서 같은 이름의 토큰을 사용하고, 값이나 사용처가 달라질 때 문서와 코드를 함께 수정한다.
